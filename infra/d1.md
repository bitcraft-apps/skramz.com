# D1 database + local/dev workflow (issue #1)

## Database

- **Name:** `skramz` — the system's only database (D1, SQLite).
- **Created with:** `pnpm exec wrangler d1 create skramz` (once per account;
  local dev needs no Cloudflare account — `wrangler dev` uses a local file).
- **Database ID:** `<D1_DATABASE_ID placeholder>` — real value lives in the
  `D1_DATABASE_ID` GitHub secret / local `.env` (gitignored), never in git.
  Paste it into `api/wrangler.toml` (`database_id`) only for `--remote` runs,
  or prefer `CLOUDFLARE_ACCOUNT_ID` + `D1_DATABASE_ID` env passthrough.

## Bindings (`api/wrangler.toml`)

| Binding | Kind | Target            |
| ------- | ---- | ----------------- |
| `DB`    | D1   | database `skramz` |
| `MEDIA` | R2   | bucket `skramz-media` |

`MEDIA` is the JS identifier for the `skramz-media` bucket (hyphens are not
valid binding names). R2 credentials/token scope are documented in
`infra/r2.md` (later issue); `.env.example` reserves the `R2_*` key names.

## Local workflow (no Docker, no server)

```bash
pnpm install          # from api/ (fresh-clone prerequisite)
task dev:api          # wrangler dev on :8787 with local D1
curl localhost:8787/healthz   # 200 {"ok":true,"db":1} via SELECT 1 on D1
task migrate          # apply api/migrations/* to local D1
```

- `task migrate:prod` (`... --remote`) is explicit-only and applies the same
  `api/migrations/` directory to production D1.
- Migrations are raw, portable SQLite in `api/migrations/` (no Postgres-isms).
- Free-tier walls: 5 GB storage, 5M row-reads / 100k row-writes per day —
  keep queries small (`SELECT 1` health checks, `LIMIT`-bounded lists).

## Secrets & rotation

- Secrets (`CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`, `D1_DATABASE_ID`,
  `INGESTION_TOKEN`, `R2_*`) live in **GitHub secrets** (CI/deploy) and
  **`wrangler secret`** (Worker runtime) — never in git, never in
  `wrangler.toml`, never in `.env.example` (keys only, values empty).
- Local overrides go in root `.env` (gitignored, loaded by Taskfile `dotenv`).
- Rotation: regenerate the token in the Cloudflare dashboard, update the
  GitHub secret / `wrangler secret put <NAME>`, redeploy. No code change needed
  since no secret value is checked in.
